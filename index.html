ygo.css

A CSS library that looks like Yu-Gi-Oh! cards. The edges are hard bevels, as in Windows 98. It styles some elements directly (buttons, fields) and gives classes for the rest. Click the attribute above to change between the light and the dark theme.

Use

Put the ygo.css folder into your project. Then add these two lines to <head>. The stylesheet loads its images and fonts from the folder assets next to it.

<script src="ygo.css/ygo.js"></script>
<link rel="stylesheet" href="ygo.css/ygo.css">

Card types

Set the card type with data-card on an element. The elements inside it get the same type. Without data-card, the type is Normal. In the dark theme, it is Dark Synchro.

Light and dark

The light theme is the default. data-theme="dark" on <html> sets the dark theme. ygo.js keeps the choice and changes the theme when you click an element with the class ygo-theme-toggle.
